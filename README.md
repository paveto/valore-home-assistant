# Valore pro Home Assistant OS

Aplikace pro zvonek Valore IP07/X6. Přímo v postranním panelu Home Assistantu
zobrazuje živý obraz, přehrává zvuk ze zvonku a nabízí tlačítko pro mluvení.
Při zazvonění může odeslat oznámení do aplikace Home Assistant na iPhonu.

## Instalace

**Repozitář přidej v Nastavení → Aplikace.** Pokud se zobrazí hlášení
„Tržiště aplikace neinstaluje“, otevři nabídku **Aplikace** a pokračuj
podle kroků níže.

1. V Home Assistant OS otevři **Nastavení → Aplikace → Instalovat aplikaci**.
2. V nabídce **⋮ → Repozitáře** přidej adresu
   `https://github.com/paveto/valore-home-assistant`.
3. Vyber **Valore**, nainstaluj ho a otevři jeho **Konfiguraci**.
4. Vyplň údaje účtu Tuya a případně akci oznámení pro svůj telefon.
5. Spusť aplikaci a otevři panel **Valore**.
